# Contributing Guidelines

Thank you for investing your time in contributing to this project!

## QA Standards
As this project is maintained by a former QA Engineer, quality is paramount.
1. **Tests:** All PRs must include relevant unit or E2E tests (Jest/Playwright).
2. **Linting:** Ensure your code passes all ESLint rules (`npm run lint`).
3. **Commit Messages:** Follow the Conventional Commits specification.

## Workflow
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Issue a Pull Request.

## 🛡️ Badges Used (Powered by Shields.io)

The `README.md` is pre-configured with premium badges. You do not need to download these; they render automatically. However, if you ever need to add more, use this format:

`https://img.shields.io/badge/<Label>-<Color>?style=for-the-badge&logo=<IconName>&logoColor=white`

**Color Guide for Future Badges:**
- **Black/Dark Grey (`000000` / `181717`)**: Use for core tools (GitHub, Next.js) or AI agents.
- **Brand Colors**: Use exact brand hex codes (e.g., `4285F4` for Google/Chrome, `0078D7` for Edge).
- **Style**: ALWAYS use `style=for-the-badge` to maintain the premium, blocky, modern aesthetic.

### Pre-configured Badges in your README:

- **Store Buttons**: Chrome Web Store, GitHub Source
- **AI/Agents**: OpenAI, Google Gemini, Playwright
- **Browser Tech**: Chrome, Edge, Manifest V3 (Custom)
- **Programming**: JavaScript, TypeScript, HTML5, CSS3
- **QA/Analytics**: Jira, Postman, MySQL, Power BI, Excel, Git

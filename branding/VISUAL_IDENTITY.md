# Visual Identity & Brand Theme

This document defines the visual standards for your entire GitHub presence, ensuring a premium, product-led aesthetic.

**Theme Name:** Deep Space / Cyber Intelligence
**Vibe:** Premium, Developer-Focused, Minimal, Futuristic, Product-Led.

## 🎨 Color Palette
Use these exact hex codes for consistency across your brand and projects like TabComet.

| Element | Color | Hex Code | Use Case |
| :--- | :--- | :--- | :--- |
| **Background** | Deep Void | `#0D1117` | GitHub Dark Mode exact match background |
| **Accent 1** | Neon Cyan | `#00D2FF` | Highlights, buttons, and tech glows |
| **Accent 2** | Cosmic Purple | `#7B2CBF` | Secondary gradients and AI-themed elements |
| **Text Primary** | Pure White | `#FFFFFF` | Main headlines and high-contrast text |
| **Text Secondary**| Astro Grey | `#8B949E` | Subtitles, code snippets, and subtle info |

## 🔠 Typography
- **Headline Font:** `Inter` or `Space Grotesk` (Bold, geometric, highly readable)
- **Code/Tech Font:** `Fira Code` or `JetBrains Mono` (For any terminal-style aesthetics or coding references)

## 🖼️ Banner Assembly Instructions

**Dimensions:** 1500px × 500px (3:1 ratio is perfect for GitHub)

1. Use the AI prompts in `prompts/BANNER_DESIGN_SPEC.md` to generate your background.
2. Open **Figma** or **Canva**.
3. Create a canvas of **1500x500 pixels**.
4. Drop in the background image.
5. Add the typography on the left side:
   - Subtitle: `<Software Builder /> & <AI Product Creator />` (`Fira Code`, Astro Grey).
   - Main Title: **Piyush** (`Inter`, Pure White).
   - Tagline: "Building software that solves real problems." (`Inter`, Astro Grey).
6. Export as a high-quality `PNG` and save as `assets/banner/banner.png`.

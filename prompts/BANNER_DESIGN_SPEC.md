# Banner Design Specification Prompts

Copy and paste these prompts into your preferred AI image generators to create the background or illustration assets for your GitHub Profile Banner.

### Option 1: Figma AI / Canva AI (For abstract geometric backgrounds)
> "Create a sleek, abstract dark mode background for a developer portfolio. Use a deep navy almost black background (#0D1117). Include subtle, glowing geometric shapes, connecting nodes, and a soft gradient mesh of neon cyan (#00D2FF) and cosmic purple (#7B2CBF). The left side should be mostly empty negative space for text overlay."

### Option 2: Midjourney (For premium 3D illustrations)
> `/imagine prompt: A high-end, isometric 3D illustration of a minimalist web browser window floating in dark space. The browser has glowing neon cyan and purple accents. Subtle glowing nodes and data streams connect to the browser, representing artificial intelligence and automation. Clean lines, dark mode aesthetic, vector style, UI/UX design, dark background, 8k resolution --ar 3:1 --v 6.0`

### Option 3: ChatGPT (DALL-E 3) (For a stylized tech concept)
> "Generate a wide, ultra-wide aspect ratio image (3:1) for a GitHub profile banner. The theme is 'Software Builder and AI Product Creator'. The background is extremely dark, almost #0D1117. On the right side, show a sleek, abstract representation of a glowing web browser with nodes of light connecting to it. The left side must be completely dark and empty so I can add my own text later. Use a color palette of deep black, glowing cyan, and cosmic purple."

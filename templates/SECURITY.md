# Security Policy

## Supported Versions
Only the latest version of the extension on the `main` branch is actively supported for security updates.

## Reporting a Vulnerability
Security is a top priority. Do NOT create a public issue for security vulnerabilities.
Instead, please email the maintainer directly. You should expect a response within 48 hours.

## Browser Extension Security
- This project adheres strictly to **Manifest V3**.
- **Content Security Policy (CSP)** is enforced.
- No `eval()` or unsafe dynamic code execution is permitted.
